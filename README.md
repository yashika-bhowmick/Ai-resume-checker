AI Resume Checker 

An AI-powered web application built with Python and Flask to analyze resumes using a local AI model.

Features:-

User signup and login
Resume text extraction from PDF and DOCX files
AI-powered resume analysis using Ollama
Dashboard and report history
Database integration

Tech Stack:-

Python, Flask, HTML, CSS, Jinja
SQLAlchemy, PyMySQL
PyPDF2, python-docx
Google Gemini API
